# 架构图
(Pty会话核心层 子进程会话核心层)+生命周期管理 | <- web层 -> 服务器
										   | <- 客户端命令处理层 | <- mcp层 | <- 认证层（支持共享内存通信和网络通信） | 		<- 客户端mcp
														  | <- CLI层  |			| 		<- 客户端cli层
														  
可以设立公共层，把都有的封装起来，但是注意不要滥用
客户端命令处理层支持+插件，客户端cli层和客户端mcp有接受来自客户端命令处理层声明的插件能力
注意客户端和守护进程可能不在同一台机子（cli的创建终端千万不能继承环境变量）

终端返回条件：
立刻返回（其他条件+等通知置位），后台检查条件，命中后推送事件
程序退出（自动） -> 死了
超时（配置）	-> 兜底
屏幕静默（可见文本）（配置） -> 兜底
查到GUI窗口（自动） -> 异常
启发式搜寻（可见文本启发式搜索）（自动） -> 补充
屏幕输出回响/隐藏字节流回响（需要扫描器读原始字节流找隐藏字节流） -> 精确命令结束
查到子进程启动->子进程终止（自动，shell才启用） -> 防止不了命令中间插内置命令
正则匹配（手动）（可见文本或者扫描器读原始字节流）
	防止回显匹配：
		- 1.利用结构差异（可见文本）
		- 2.利用回显原字符而输出是转义后的真实字节这个差异（扫描器读原始字节流）

终端返回数据
取屏幕（可见文本）
取屏幕SVG
取屏幕全量输出（全量输出指的是包含滚动历史的可见文本）
取全量输出的最后 N 行
取全量输出中指定范围的行
取可见屏幕的第 N 列
取可见屏幕diff（本次可见文本和上次可见文本做diff）
数据流offset（原始字节流，定位后strip序列码）
正则匹配（可见文本中grep）
